# Guided Hacking Offset Dumper (فارسی)

یک ابزار مدرن و قدرتمند برای اسکن امضا (Signature Scanning) و استخراج آفست‌های بازی (Offset Dumping). این ابزار به شما اجازه می‌دهد تا به سرعت هدرهای C++، جداول Cheat Engine و پروژه‌های ReClass.NET را برای هر بازی، چه در حال اجرا (Runtime) و چه از روی فایل‌های دیسک (Disk)، تولید کنید.

![image](resources/code.png)

## قابلیت‌های کلیدی
- **تولید جدول Cheat Engine (.ct):** شامل لیست بازیکنان و انتیتی‌ها به صورت سازمان‌یافته.
- **تولید پروژه ReClass.NET (.rcnet):** کلاس‌های Netvar را به صورت خودکار به ساختارهای ReClass تبدیل می‌کند.
- **تولید هدر C++ (.hpp):** آفست‌های استخراج شده را در یک فایل هدر تمیز و آماده استفاده قرار می‌دهد.
- **پشتیبانی از اسکن دیسک:** استخراج آفست‌ها بدون نیاز به اجرای بازی.
- **پشتیبانی از Netvars:** استخراج خودکار Netvarها برای بازی‌های مبتنی بر موتور Source (مانند CS:GO).
- **پیکربندی ساده:** استفاده از فایل‌های JSON برای تعریف امضاها و تنظیمات هر بازی.

## آموزش کامل استفاده (از دانلود تا دامپ)

### ۱. پیش‌نیازها
قبل از شروع، مطمئن شوید که موارد زیر را نصب دارید:
- **Visual Studio 2022** (با پکیج Desktop development with C++)
- **CMake** (اختیاری، برای بیلد با VS Code)

### ۲. دانلود و نصب
ابتدا پروژه را از گیت‌هاب کلون کنید یا فایل ZIP آن را دانلود کنید:
```bash
git clone https://github.com/GuidedHacking/GH-Offset-Dumper.git
cd GH-Offset-Dumper
```

### ۳. بیلد کردن (ساخت برنامه)
#### با استفاده از Visual Studio:
1. فایل `GH-Offset-Dumper.sln` را باز کنید.
2. حالت بیلد را روی **Release** و پلتفرم را روی **x64** (یا x86 بسته به بازی هدف) قرار دهید.
3. از منوی Build، گزینه **Build Solution** را انتخاب کنید.
4. فایل‌های اجرایی در پوشه `bin` یا پوشه‌های خروجی پروژه ساخته می‌شوند.

### ۴. پیکربندی (Config)
برنامه بر اساس فایل‌های JSON کار می‌کند. یک نمونه ساده در `configs/config.json` وجود دارد. شما باید امضاهای (Signatures) مورد نظر خود را در این فایل وارد کنید.

**نکته مهم:** اگر بازی ۶۴ بیتی است، از نسخه x64 و اگر ۳۲ بیتی است از نسخه x86 دامپر استفاده کنید.

### ۵. نحوه اجرای دامپ

#### روش اول: دامپ از بازی در حال اجرا (Runtime)
1. بازی مورد نظر را اجرا کنید.
2. فایل JSON پیکربندی خود را کشیده و روی فایل `.exe` دامپر رها کنید (Drag & Drop).
3. دامپر به صورت خودکار به بازی متصل شده، اسکن را انجام می‌دهد و نتایج را در یک پوشه جدید ذخیره می‌کند.

#### روش دوم: دامپ از روی فایل‌های دیسک (بدون اجرای بازی)
1. در فایل JSON، مقدار `"fileonly": true` را قرار دهید.
2. مسیر فایل اجرایی بازی را در فیلد `"exefile"` وارد کنید.
3. فایل JSON را روی دامپر رها کنید.

### ۶. خروجی‌ها
پس از اتمام عملیات، پوشه‌ای با نام بازی شما ایجاد می‌شود که شامل فایل‌های زیر است:
- `offsets.hpp`: قابل استفاده مستقیم در پروژه‌های C++.
- `offsets.ct`: جدول آماده برای Cheat Engine.
- `offsets.rcnet`: پروژه آماده برای ReClass.NET.

## راهنمای تنظیمات JSON

ساختار فایل کانفیگ به شرح زیر است:

```json
{
  "executable": "csgo.exe",           // نام پروسه بازی
  "filename": "CSGO_Offsets",         // نام پوشه خروجی
  "signatures": [
    {
      "name": "dwLocalPlayer",        // نام آفست
      "pattern": "8D 34 85 ? ? ? ? 89 15 ? ? ? ? 8B 41 08 8B 48 04 83 F9 FF", // الگوی اسکن
      "module": "client.dll",         // ماژول هدف
      "relative": true,               // آیا آفست نسبت به شروع ماژول باشد؟
      "extra": 3                      // مقدار اضافی برای جمع کردن با نتیجه
    }
  ],
  "netvars": [                        // مخصوص بازی‌های سورس
    {
      "name": "m_iHealth",
      "table": "DT_BasePlayer",
      "prop": "m_iHealth"
    }
  ]
}
```

## عیب‌یابی (Troubleshooting)
- **خطای پیدا نشدن پروسه:** مطمئن شوید بازی در حال اجراست و دامپر را با دسترسی Administrator اجرا کرده‌اید.
- **پیدا نشدن الگو (Pattern):** احتمالا امضا قدیمی شده است. باید امضای جدیدی از سایت‌هایی مثل GuidedHacking پیدا کنید.
- **خطای معماری (Architecture):** مطمئن شوید معماری دامپر (x86/x64) با بازی یکی است.
